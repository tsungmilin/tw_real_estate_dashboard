### 2.1 來源清理

|---|---:|---:|---:|
| DTA 底稿 | 4,380,208 | 4,261,466 | 118,742 |
| 15 個 MOI 批次合計 | 538,868 | 529,260 | 9,608 |

DTA 原始檔有 63 欄、14,682,511,713 bytes，SHA-256 為 `1d81eb74a5c7f3607b93966732b90a7e3b8cdf5debacf905b67e1afab86b25b2`。DTA 清理期間為 2012-08 至 2024-12，且 `4,380,208 = 4,261,466 + 118,742`。

MOI 清理範圍包含季度檔 `114S1` 至 `115S2`，以及 `2026-07-01` 至 `2026-09-21` 的定期發布檔。529,260 筆清理後資料包含 529,240 個唯一 ID：11,700 個與 DTA 重疊，20 個跨 MOI 批次重複，其中 8 個內容曾修訂。全部清理稽核皆為 `success`，缺少 ID、衝突 ID 與無法對應行政區皆為 0。

最新批次 `2026-09-21` 有 8,093 筆輸入、7,992 筆清理後資料及 101 筆排除資料。各批次的完整排除原因與品質分布保存在本機 `data/audit/`，不在公開文件重複列出。

## 3. Tableau 與公開交付物

`housing_portfolio.twbx` 內含 Hyper 擷取檔，共 19 張工作表與兩個儀表板：

- 「台灣房市月度概覽」
- 「縣市房價分析」

可攜版已通過離線切換頁面、月份、指標與縣市的驗收。Hyper 內含三張分析表與 368 筆行政區維度，共 64,929 筆；預設月份為 2026-06，主要縣市為臺北市，比較縣市預設為新北市、臺中市與新竹市。

`housing_portfolio.twbx` 已由 PostgreSQL 即時版重新建立完整擷取檔，並覆寫既有 Tableau Public 工作簿。可攜版與公開版本均同步至 2026-06；手機版面不在第一版正式支援範圍。

## 4. 已完成的系統能力

- DTA 與 MOI 共用 24 欄原始欄位契約及同一套清理流程。
- MOI ZIP 結構檢查、買賣主檔轉接、SHA-256、修訂版及發布紀錄已完成。
- 新竹市、嘉義市暫時映射東區；`台東市`、`台西鄉` 字形差異已處理並納入稽核。
- 清理輸出、排除資料、Parquet 讀回與筆數對帳已完成。
- PostgreSQL `staging → core → analytics` 支援初始化、增量更新、冪等重跑、失敗重試與完整驗證。
- 全國、縣市及行政區分析表支援完整重建與批次增量更新。
- Tableau 可攜版已內嵌必要分析表與行政區維度，不包含原始或逐筆交易資料。
